# Tasks

Field bounds are named rather than restated. Where a task says **identifier**,
**label**, **address component**, **amount**, **magnitude**, **percentage**,
**instant**, or **year**, it means the rule the capability's shared lexical requirement fixes.
Restating a bound here would be a second copy of it.

## 1. Canonical appraisal records

- [ ] 1.1 Add the bounded address and legal-description value objects — Add `libs/property-tax-domain/src/property_tax_domain/address.py` defining three frozen slotted value objects. `SitusAddress` carries optional `street_address`, `unit`, `city`, `state_code`, `postal_code`, each an **address component**. `MailingAddress` carries those plus optional `addressee` and `country_code`, each an **address component**. `LegalDescription` carries a required `text` as a **label** and optional `subdivision`, `block`, `lot` as **address components**. Reject an object whose every field is absent. Carry no provenance, no publication flag, permission, visibility, or redaction-override field, and no free-form payload. Import only the standard library.
<!-- countyforge-task: 1.1 paths=libs/property-tax-domain/src/property_tax_domain/address.py checks=repo.check risk=higher_risk prerequisites=D9 -->

- [ ] 1.2 Add account identity and the account snapshot — Add `libs/property-tax-domain/src/property_tax_domain/account.py`. `AccountIdentity` is a frozen slotted value object of exactly `jurisdiction: Jurisdiction` and `source_account_id` as an **identifier**, with no provenance. Validate the identifier lexically only: do not attempt to determine which source field supplied it, because a jurisdiction and a string cannot distinguish an approved account key from an owner-row discriminator carrying the same characters. `AccountSnapshot` carries `identity: AccountIdentity`, `provenance: DomainProvenance`, optional `source_as_of` as an **instant** excluded from equality and hashing, and optional composed `situs` and `legal_description`. Carry **no** `ReleaseIdentity` field: the provenance is the release authority and a second copy would be two facts that must agree. Expose the release through the provenance. Require at construction that the identity's jurisdiction equals the jurisdiction of the release the provenance names, so an identity from one county cannot be paired with another county's release and then be agreed with by every child. Define equality and hashing as structural over every field except `source_as_of`, and publish the grain as a read-only property named `grain` returning the tuple `(AccountIdentity, ReleaseIdentity)` in that order, so two snapshots observed in different artifacts of one release share a grain, remain unequal, and each keep their own lineage, and consumers key on one published shape rather than each choosing an accessor.
<!-- countyforge-task: 1.2 paths=libs/property-tax-domain/src/property_tax_domain/account.py checks=repo.check risk=higher_risk prerequisites=D1,D9,D10,D13,1.1 -->

- [ ] 1.3 Add owner observations and owner associations — Add `libs/property-tax-domain/src/property_tax_domain/owner.py`. `OwnerObservation` carries `snapshot: AccountSnapshot`, `owner_name` as a **label**, optional composed `mailing_address`, and `provenance`. `OwnerAssociation` carries `snapshot: AccountSnapshot`, `owner: OwnerObservation`, optional `ownership_percentage` as a **percentage**, optional `source_discriminator` as an **identifier**, and `provenance`. Require at construction that each record's provenance release equals its parent snapshot's provenance release, and that the association's snapshot equals its owner observation's. Derive no owner identity from name or address and provide no equality making two observations one owner. Keep the discriminator optional so a county whose owner-row grain its contract leaves unresolved stays representable.
<!-- countyforge-task: 1.3 paths=libs/property-tax-domain/src/property_tax_domain/owner.py checks=repo.check risk=higher_risk prerequisites=D2,D10,D13,1.1,1.2 -->

- [ ] 1.4 Add the canonical value vocabulary and account-level value observations — Add `libs/property-tax-domain/src/property_tax_domain/value.py`. `ValueKind` is a closed `StrEnum` of exactly `market`, `appraised`, `assessed`, with no fallback member and no open-string constructor. `AppraisalValueObservation` carries `snapshot: AccountSnapshot`, `kind: ValueKind`, `amount` as an **amount**, and `provenance`, requiring release agreement with its snapshot. Add no `taxable` member and no land, improvement, agricultural, timber, productivity, or cap kind. Expose no function, mapping, or constructor translating a source-native label into a kind: that mapping belongs to the county-aware boundary and needs an accepted contract.
<!-- countyforge-task: 1.4 paths=libs/property-tax-domain/src/property_tax_domain/value.py checks=repo.check risk=higher_risk prerequisites=D3,D10,D13,1.2 -->

- [ ] 1.5 Add the owner-scoped value allocation — Add `OwnerValueAllocation` to `libs/property-tax-domain/src/property_tax_domain/owner.py` carrying `association: OwnerAssociation`, `kind: ValueKind`, `amount` as an **amount**, and `provenance`, requiring release agreement with its association. This is the shape owner-scoped value allocations live in; without it the requirement that they hang off the association describes something unrepresentable. Add no field on the snapshot, the association, or the allocation that could hold an account-level total assembled from allocations.

- [ ] 1.6 Add taxing-unit observations and taxable values at their grain — Add `libs/property-tax-domain/src/property_tax_domain/taxing_unit.py` defining `TaxingUnitObservation` carrying `snapshot: AccountSnapshot`, `unit_code` as an **identifier**, optional `unit_name` as a **label**, and `provenance`, all source-native, named so it cannot be confused with the canonical `Jurisdiction` and declaring no canonical cross-county registry. Add `TaxableValueObservation` to `libs/property-tax-domain/src/property_tax_domain/value.py` carrying `snapshot: AccountSnapshot`, `taxing_unit: TaxingUnitObservation`, `amount` as an **amount**, `basis` as a **label** preserved source-native, and `provenance`. Require that the taxing unit's snapshot equals the taxable value's and that releases agree. A taxable value unqualified by a taxing unit must have no constructible form.

- [ ] 1.7 Add exemption observations with explicit scope — Add `libs/property-tax-domain/src/property_tax_domain/exemption.py` defining `ExemptionScope` as a closed `StrEnum` of `account` and `owner_association`, and `ExemptionObservation` carrying `snapshot: AccountSnapshot`, `classification` as a **label** preserved verbatim source-native, optional `amount` as an **amount**, required `scope: ExemptionScope`, `association: OwnerAssociation | None`, and `provenance`. Require the association present when and only when the scope is owner-scoped, that its snapshot equals the exemption's, and that releases agree. Do not infer scope from whether the reference is present. Define no canonical exemption vocabulary and derive no taxable value from exemptions.

- [ ] 1.8 Add land and improvement child observations — Add `libs/property-tax-domain/src/property_tax_domain/land.py` defining `LandObservation` and `libs/property-tax-domain/src/property_tax_domain/improvement.py` defining `ImprovementObservation`. Each carries `snapshot: AccountSnapshot`, optional `source_discriminator` as an **identifier**, optional source-native `classification` as a **label**, optional `area` as a **magnitude**, which unlike an **amount** rejects a negative value because a measured extent has none, with `area_unit` as a **label**, and `provenance`, requiring release agreement. An improvement additionally carries optional `year_built` as a **year**. Reject an area without its unit and a unit without an area. Keep them separate types rather than one shared shape with mostly-absent fields. Invent no natural key and treat no sequence number, row number, building number, or ordering as stable business identity.

- [ ] 1.9 Add the geometry enrichment — Add `libs/property-tax-domain/src/property_tax_domain/geometry.py` defining `GeometryEncoding` as a closed `StrEnum` of `wkb` and `wkt`, and `GeometryObservation` carrying `snapshot: AccountSnapshot`, `encoding: GeometryEncoding`, `payload: bytes | str` non-empty and at most 8 MiB, measured as the length of the `bytes` or of the `str` encoded as UTF-8, with `bytes` required for `wkb` and `str` for `wkt`; required `crs` of 1 through 64 characters carrying no control character, holding at least one non-whitespace character, and stated as the source stated it; and `provenance`, requiring release agreement. Parse, validate, reproject, and interpret nothing. Import no geospatial library, spatial database extension, or object-store client.
