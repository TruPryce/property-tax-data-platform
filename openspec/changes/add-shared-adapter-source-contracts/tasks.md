## 1. Shared Vendor-Neutral Source Contracts

<!-- countyforge-task: 1.1 paths=libs/property-tax-adapters/src/property_tax_adapters/sources/contracts.py checks=repo.check risk=higher_risk prerequisites=D1,D2,D3,D4,D6 -->
- [ ] 1.1 Add the shared source contracts module — Add `property_tax_adapters/sources/contracts.py` with the three frozen slotted dataclasses issue #43 D7 approves. `SourceNativeValue` carries `source_field`, `lexical_text` typed `str | None`, `value` typed `str | int | Decimal` with no `None` member, `precision` and `scale` each typed `int | None`, and `classification` fixed to the literal `source-native`; it rejects a blank or whitespace-only `source_field` and rejects `precision` supplied without `scale` or the reverse. `lexical_text` is `None` only where the source carries no text and is `""` where an empty text was observed, so an empty extra column keeps the value Dallas produces today. `SourceProvenance` carries `jurisdiction_code`, `release_identifier`, `source_member_name`, `source_row_number`, `parser_contract_version`, `layout_fingerprint`, and D7's six optional fields `table_name`, `source_family`, `source_year`, `source_status`, `observed_fields`, and `normalized_fields`, and no field beyond that list; it rejects a nonpositive row number and a `jurisdiction_code` that is not a lowercase state prefix, a hyphen, and a county slug. `AppraisalSourceRecord` carries `jurisdiction_code`, `source_account_id` typed `str | None`, `source_native_identifiers`, `appraisal_year`, `source_family` typed `str | None`, `source_status` typed `str | None`, `parcel_reference` typed `str | None`, `source_native_values`, and a required `provenance`; it rejects `""` in `source_account_id`, `source_family`, `source_status`, and `parcel_reference` so absence is `None`, rejects a value-map key that does not equal its value's `source_field`, and rejects a `jurisdiction_code` disagreeing with its provenance. Both mappings are wrapped so a caller cannot mutate a constructed record through the mapping it passed. These are authoring defects in trusted code, so they raise `ValueError` and produce no diagnostic. The module declares no county name, no county field name, no threshold, and no policy, defines no owner, mailing, or situs field, exposes no untyped or free-form payload attribute, and imports only the standard library.
