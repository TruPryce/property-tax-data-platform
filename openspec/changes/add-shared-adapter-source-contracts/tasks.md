<!-- countyforge-task: 1.1 paths=libs/property-tax-adapters/src/property_tax_adapters/sources/contracts.py checks=repo.check risk=higher_risk prerequisites=D1,D2,D3,D4 -->
- [ ] 1.1 Add the shared source contracts module — Add `property_tax_adapters/sources/contracts.py` declaring `SOURCE_CONTRACT_VERSION` and three frozen slotted dataclasses. `SourceNativeValue` carries `source_field`, `lexical_text`, `value` typed `str | int | Decimal | None`, and `classification` fixed to the literal `source-native`, rejecting a blank `source_field` at construction. `SourceProvenance` carries `jurisdiction_code`, `release_identifier`, `source_member_name`, `source_row_number`, `parser_contract_version`, and `layout_fingerprint`, rejecting a nonpositive row number and a `jurisdiction_code` that is not a lowercase state prefix plus county slug. `AppraisalSourceRecord` carries `jurisdiction_code`, `source_account_id` typed `str`, `appraisal_year`, `source_family`, `source_status`, `parcel_reference` typed `str | None`, `source_native_identifiers`, `source_native_values`, and a required `provenance`, rejecting a blank account identifier, a mapping key that does not equal its value's `source_field`, and a `jurisdiction_code` disagreeing with its provenance. Mappings are wrapped so a caller cannot mutate a constructed record through the dictionary it passed. These are authoring defects in trusted code, so they raise `ValueError` and produce no diagnostic. The module contains no county name, no county field name, no threshold, and no policy, and imports only the standard library.
