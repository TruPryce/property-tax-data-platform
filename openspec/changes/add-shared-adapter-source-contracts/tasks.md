## 1. Shared Vendor-Neutral Source Contracts

<!-- countyforge-task: 1.1 paths=libs/property-tax-adapters/src/property_tax_adapters/sources/contracts.py checks=repo.check risk=higher_risk prerequisites=D1,D2,D3,D4,D6 -->
- [ ] 1.1 Add the shared source contracts module — Add `property_tax_adapters/sources/contracts.py` declaring `SOURCE_CONTRACT_VERSION` and three frozen slotted dataclasses. `SourceNativeValue` carries `source_field`, `lexical_text` typed `str | None`, `value` typed `str | int | Decimal | None`, and `classification` fixed to the literal `source-native`, rejecting a blank or whitespace-only `source_field`. `SourceProvenance` carries `jurisdiction_code`, `release_identifier`, `source_member_name`, `source_row_number`, `parser_contract_version`, `layout_fingerprint`, and `source_contract_version` defaulted to the module constant, rejecting a nonpositive row number and a `jurisdiction_code` that is not a lowercase state prefix, a hyphen, and a county slug. `AppraisalSourceRecord` carries `jurisdiction_code`, `source_account_id` typed `str | None`, `appraisal_year`, `source_family` typed `str | None`, `source_status` typed `str | None`, `parcel_reference` typed `str | None`, `source_native_identifiers`, `source_native_values`, and a required `provenance`; it rejects an empty string in any nullable text field so that absence is `None` and never `""`, rejects a value-map key that does not equal its value's `source_field`, and rejects a `jurisdiction_code` disagreeing with its provenance. Both mappings are wrapped so a caller cannot mutate a constructed record through the mapping it passed. These are authoring defects in trusted code, so they raise `ValueError` and produce no diagnostic. The module declares no county name, no county field name, no threshold, and no policy, defines no owner, mailing, or situs field, exposes no untyped or free-form payload attribute, and imports only the standard library.
